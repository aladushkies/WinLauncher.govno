# P1 — протокол проверки на Samsung SM-T555 (Android 7.1.1)

Перед проверками оставить два тестовых окна открытыми. Сначала убедиться, что сервер отвечает на `ping` и `tasks`.

- [ ] RootServer стартует через используемый SU (SuperSU или Magisk).
- [ ] `peerCredentials` читается и UID клиента совпадает с UID APK.
- [ ] `getAllStackInfos` возвращает стеки и валидные массивы taskIds/taskNames/taskBounds.
- [ ] Для одного тестового task вызвать `front`, затем проверить фокус и порядок.
- [ ] `resizeTask(id, Rect, 1)` двигает окно; сверить фактические bounds.
- [ ] `resizeTask(id, Rect, 0)` фиксирует bounds.
- [ ] `moveTaskToStack(id, 2, true)` переводит тестовое окно в freeform.
- [ ] `moveTaskToStack(id, 1, false)` проверяется отдельно и только на тестовой задаче.
- [ ] Проверить повторное подключение после закрытия/перезапуска APK.

Синтаксис команд `am` из исходного ТЗ здесь не используется: этот инкремент вызывает Binder напрямую. Для сопоставления выводов можно отдельно снять `am stack list` и `dumpsys activity activities` на устройстве.
